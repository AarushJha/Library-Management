# 📚 Library Management System in Python

A basic, clean and intuitive console-based **Library Management System** built in pure Python. This project helps you manage book inventories, track issued and returned books, and maintain library records efficiently.

## ✨ Project Features

* **Add new books:** Add fresh titles and inventory into the system.
* **Display all books:** View a complete list of all books currently tracked by the library.
* **Search for a book:** Look up specific books quickly.
* **Issue a book:** Check out a book to members and update its availability status.
* **Return a book:** Process incoming book returns back into the library.
* **Delete a book:** Remove outdated or lost books from the system.
* **Exit the program:** Safely close the application.

## 💡 How to Use

This project runs on pure Python with no external dependencies and is designed to be executed inside a **Jupyter Notebook**. Simply run the code cells to interact with the system menu prompts.

## 🛠️ Technologies Used

* Python (utilizing lists, dictionaries, and loops)
